# Погодний дашборд

Навчальний вебзастосунок для перегляду поточної погоди та прогнозу на тиждень для обраного міста.

## Функціональність

- Пошук погоди за назвою міста
- Відображення поточної температури та стан погоди
- Прогноз погоди на декілька днів
- Корисні щоденні поради щодо погоди
- Зручний та сучасний веб-інтерфейс

## Технології

- **HTML5** — семантична розмітка
- **CSS3** — стилізація та адаптивна верстка
- **JavaScript** — логіка та інтерактивність

## Структура проєкту

- `index.html` — головна HTML-сторінка
- `css/style.css` — стилі оформлення
- `js/app.js` — клієнтський скрипт
- `assets/img/` — зображення та іконки погоди
- `.gitignore` — конфігурація ігнорування для Git
