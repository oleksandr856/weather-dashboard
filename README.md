Погодний дашборд
Практична робота №1 з дисципліни Програмування веб-застосувань.

Варіант: 1 (`weather-dashboard`)

Про проєкт

Це базовий HTML-каркас для майбутнього погодного дашборду. На цьому етапі створено структуру файлів і розмітку з коментарями заглушками для майбутніх розділів.

Структура проєкту

`index.html` — головний HTML5-файл
`css/style.css` — стилі
`js/app.js` — скрипти
`assets/img/` — картинки та іконки
`.gitignore` — файл ігнорування для Git

Заплановані розділи

1. Шапка з назвою та пошуком міста
2. Блок поточної погоди
3. Прогноз погоди на кілька днів
4. Підвал з посиланням на джерело даних

Як запустити

1. Склонувати репозиторій.
2. Відкрити папку в VS Code.
3. Запустити `index.html` через Live Server.
